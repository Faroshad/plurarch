# Langford A: the Plurarch experiment model (v3)

Plurarch now runs on a real building instead of the generated pavilion: **Langford Architecture
Center, Building A** (Texas A&M, College Station). It is modelled Revit-first in
`E:\Academic\PhD\Fall 2026\AI Workshop\LangfordA_Fresh\P1_RevitFirst` (read-only source; never
write there).

```
Revit (truth)  revit/LangfordA_Plurarch.rvt   copy of P1 LangfordA_P1.rvt; the AI applies votes here
Rhino (show)   rhino/LangfordA_Plurarch_render.3dm   copy of P1 render scene (textures, terrain, trees)
Phones/stage   site/models/langford/*   light geometry from the P1 IFC (same element marks)
Data           config/langford/elements.json   which elements each question controls (generated)
```

Every element keeps the P1 identity: `Mark` (e.g. `SE-CW-2`), `RevitElementId`, IFC `GlobalId`.

## The four questions (`config/parameters.json`)

| key | type | range | Revit elements | what a value means |
|---|---|---|---|---|
| `infill_finish` | choice | `concrete` · `aluminium` · `fritted_glass` | the solid curtain panels (type `System Panel:Solid`) | the finish material of every solid infill panel |
| `se_glass_share` | slider | 40–100 %, step 10 | the SE studio façade curtain panels | share of those panels that are glazed (`System Panel:Glazed`); the rest become solid infill |
| `fin_depth` | slider | 0–1.2 m, step 0.3 | new walls of type `ARCA Fin/Curb - Concrete 200`, mark `PLX-FIN-<n>` | sunshade fins on the SE glass (30 fins, two per bay); 0 = none |
| `skylights_open` | slider | 0–12, step 2 | the 12 north-light roof lanterns (`SKY-*`, glazing curtain walls) | how many lanterns stay glazed; the others get a solid panel |

Defaults equal the building as modelled (computed by the prep script from the real panel counts).

## The plan rule (identical in Python and JavaScript; a parity test keeps them equal)

```
glazed SE panels  = the first round(share/100 * N) panels by rank; the others solid   (round half up = floor(x + 0.5);
                    with N = 142 and steps of 10 % no value is ever a half, so Math.round agrees)
glazed lanterns   = the first n lanterns by index; the others solid
fins              = for every anchor, a wall from base along dir with length = depth (none when 0)
solid finish      = materials[infill_finish] on the solid panel type (all solid panels share it)
```

- Python: `design_mcp/langford_plan.py`: `plan(params) -> Plan` and `diff(plan, revit_state) -> ops`
- JavaScript: `site/js/model/langford.js`: `buildLangford(params) -> Model` (the docs/MODEL.md
  contract: materials, parts, pins, tour, walkable, bounds), with the same rule applied to the base
  geometry plus generated fin hexahedra

## Applying a decision to Revit (`design_mcp/revit_apply.py`)

- KenLP RevitMCPServer HTTP add-in, `127.0.0.1:7892`, bearer token in
  `%APPDATA%\Autodesk\Revit\Addins\2027\revit-mcp-token.txt`. Batch = one transaction.
- **Document guard:** every write first checks `get_document_info`. The active document must be
  `LangfordA_Plurarch` with its path inside this repo's `revit/` folder. Otherwise nothing is written
  and the result says why. This never touches another project or the P1 source file.
- Operations: `change_element_type` (panels glazed ↔ solid), `set_parameter` (the solid panel type
  material), `delete_elements` (old `PLX-FIN-*`), `create_wall` (new fins), all in ONE batch (one
  transaction). Then `import_parameters` sets `Mark` = `PLX-FIN-<n>` and `Comments` on the new fins (a
  second small batch: the add-in cannot reference ids created in the same batch). A fin-type wall with
  no Mark (left by an interrupted second step) is treated as a stray fin and replaced on the next apply.
- Every HTTP call has a 20 s cap and the whole apply has a 75 s deadline (`PLURARCH_REVIT_DEADLINE_S`).
  `PLURARCH_REVIT=off` (unit tests, judgment suite, `test-agent`, health check) never touches Revit.
- `reset-session` re-applies the defaults with the original finish (the as-modelled solid panels have no
  material), so the copy returns to the as-built: no `PLX-FIN-*`, every panel as modelled.
- Idempotent: read the current state, compute the diff, apply only the changes, then read back and
  verify against the plan.
- Best effort by default (`config/local.json` `"revit_required": false`): if Revit is unreachable,
  the state file, Rhino and the phones still update, and the decision records "Revit: not applied
  (reason)". With `true`, set_parameters refuses instead.

## Reviewer tools (design-mcp)
`get_schema`, `get_project_brief`, `get_parameters`, `evaluate` (pure), `set_parameters` (now also
applies to Revit and returns the per-operation result), and **`get_revit_state`** (read-only: SE
glazed and solid panel counts, open lanterns, fins present with their depth, solid finish material, and
whether it matches the applied parameters).

## Rhino (`grasshopper/langford_builder.py`, run by the same Grasshopper loader and Timer)
Applies the plan to the render scene objects by Revit mark: panel materials (glazed glass / the
solid finish), lantern glazing vs solid, and fin breps on layer `Plurarch::Fins` (replaced on
change). It reads `state/parameters.json` only when it changes, and keeps the last good state.

## Phone and stage
`site/js/model/langford.js` replaces `pavilion.js` as the model source (same Model contract). The
base geometry `site/models/langford/base.json` (+ `base.bin`) is fetched once (target < 3 MB), then
`buildLangford(params)` only re-tags panel materials and adds fins, so a rebuild stays fast. The Tour is
an exterior walk around the real building.

## As built, and what the prep found (2026-10-01)
- **As built** = `concrete / 100 % / 0 m / 12`: all 142 SE lites and all 12 lanterns glazed, no fins. It fails
  the brief on purpose (rule `glass_needs_fins`, cooling 73.0 > 68): the retrofit premise. A vote for it
  is MODIFIED with the minimum fins (0.6 m); REJECTED keeps it only when nothing valid exists within the
  limits (the validator allows a REJECTED decision to keep a non-compliant current design).
- **SE lites**: the P1 ribbon lites are full height (sill to head), 9 per bay; the 142 head slivers above
  them (2–163 mm, under 0.25 m²) and the entrance transom/doors are not part of the question.
- **Ranking** (rank 0 = glazed longest): edge lites next to the piers/towers go solid first, ring by ring
  toward each bay centre (a central vision band stays), lower floors first, outer bays first, then x.
- **Lantern order**: SKY-01 12 06 07 03 10 02 11 04 09 05 08 (point-symmetric pairs, one per step).
- **Fins**: on the SE studio glass only. 30 anchors: the third
  points of every full bay (mullion lines 3 and 6 of 9, spacing 3.77 m; the 3.6 m piers act as the
  bay-end fins), none in L2 bay 2 (the quad entrance). Each fin runs from its level floor to the window
  head (3.40–3.54 m), 20 mm in front of the host wall face, direction −Y.
- **Finish materials**: concrete = `ARCA Bush-hammered Architectural Concrete`, aluminium = `Aluminum`,
  fritted glass = `Glass` (P1 has no fritted material). The solid type (id 62119) is shared with the 14
  penthouse louvre panels, so they follow the finish too.
- **Frames**: everything is in the Revit model frame; the IFC/Rhino ENU frame is it rotated +39.35° about Z.
